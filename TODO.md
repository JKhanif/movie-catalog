Бизнес-требования
Сервис — публичный каталог фильмов (можно книги/игры, на вкус). Любой посетитель
может смотреть список фильмов, открывать карточку и читать отзывы. У каждого
фильма есть жанры (их может быть несколько) и отзывы с оценками. В карточке
фильма видны средняя оценка и количество отзывов. Посетители могут оставлять
отзывы. Наполнением каталога (добавление/редактирование фильмов и жанров)
занимается администратор.

Технические требования
Сущности
[x] Фильм: название, год, описание, режиссёр.
[x] Жанр: название.
[x] Отзыв: автор (просто имя строкой), оценка (1–10), текст, дата.
[x] Связи: фильм ↔ жанры (многие-ко-многим), фильм ↔ отзывы (один-ко-многим)

Эндпоинты (публичные, без авторизации)
[ ] GET /movies — список фильмов. Поддерживает фильтры (по жанру, по году, по минимальной средней оценке), 
сортировку (по году, по средней оценке, по дате добавления) и пагинацию (limit/offset или page/size). 
В каждом элементе — средняя оценка и кол-во отзывов.
[ ] GET /movies/{id} — карточка фильма со списком жанров, средней оценкой и кол-вом отзывов.
[ ] GET /movies/{id}/reviews — отзывы фильма с пагинацией.
[ ] POST /movies/{id}/reviews — оставить отзыв.
[ ] GET /genres — список жанров

Эндпоинты (только администратор)
[ ] POST /movies , 
[ ] PATCH /movies/{id} , 
[ ] POST /genres , 
[ ] DELETE /genres/{id}

Авторизация
[ ] DELETE /movies/{id}
Минимальная: один статический админ-токен из переменной окружения.
Админские эндпоинты требуют заголовок 
Authorization: Bearer <token> ,
остальные открыты. Полноценные пользователи здесь не нужны — это будет в
проекте 2.

Грабли, на которые надо обратить внимание
Средняя оценка: считать на лету каждый раз через 
AVG() в запросе или хранить
денормализованно (то есть как отдельное поле в БД)?
Удаление жанра, который привязан к фильмам, — что должно произойти?
(Запретить / отвязать.)
Параметры пагинации и фильтров надо валидировать: 
limit=-5 или 
page=abc →
400, а не паника

Задание на звёздочку
Полнотекстовый поиск по названию/описанию.
Эндпоинт «топ-10 фильмов по оценке» (с порогом по минимальному числу
отзывов, чтобы фильм с одним отзывом «10/10» не вылезал вверх)
